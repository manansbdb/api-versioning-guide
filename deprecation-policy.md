# Deprecation Policy Sample / Amostra de Política de Depreciação

## English

1. Announce deprecation in release notes and `Sunset` / `Deprecation` headers when applicable.
2. Keep the old version available for at least **N months** (team-defined).
3. Provide a migration guide with request/response diffs.
4. Monitor usage; remove only after traffic is near zero or after the sunset date.

## Português

1. Anuncie a depreciação nas notas de release e headers `Sunset` / `Deprecation` quando aplicável.
2. Mantenha a versão antiga disponível por pelo menos **N meses** (definido pela equipa).
3. Forneça guia de migração com diffs de request/response.
4. Monitore o uso; remova só após tráfego residual ou após a data de sunset.
